# Klinik Dr Prevents — Master Staff Portal

A unified internal staff portal developed for Klinik Dr Prevents to simplify daily clinic operations by bringing four essential tools into one website.

## Integrated Modules

1. **Doctor's Roster** — View doctor schedules, shifts, and branch assignments.
2. **Pantai Laboratory Catalogue** — Search laboratory tests and reference information.
3. **Panel Finder** — Search and manage clinic panel information.
4. **Branch Finder & Map** — Locate clinic branches and access map-based navigation.

## Key Features

- Centralized navigation through four top tabs.
- Consistent interface based on the Doctor's Roster design.
- Dark and light theme support.
- Mobile and desktop accessibility.
- Existing module functions retained within the unified interface.
- Single HTML entry point for GitHub Pages deployment.

## Deployment

1. Upload the master HTML file to the repository.
2. Rename the file to `index.html`.
3. Navigate to Settings > Pages.
4. Select Deploy from a branch.
5. Choose `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the website.

## Data and Synchronization

This version consolidates the four tools into one interface. Cross-device live synchronization has not yet been verified or configured for the unified deployment.

Some application data is stored in browser localStorage. A shared backend is required for reliable multi-device synchronization of editable data.

Keep the four original repositories available until the master portal has been fully tested and validated.
